# 🧪 Organo Lab Soil Kits Calculator

> 🌱 A customizable soil calculator app used by **Organo Lab ©** to enhance product experience  
> 📦 Client-side static export built with **TypeScript** + **Webpack**

---

## 📦 Project Type

This is a **client-only static application** meant to be integrated into a **WordPress** system as part of Organo Lab's customizable tools.  
The search inputs are **non-functional by design** (no backend/server integration).
